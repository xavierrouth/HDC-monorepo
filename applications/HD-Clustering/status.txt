== Knobs ==

ENCODING_DIM    [default: 1024]  Hypervector dimensionality. Powers of 2 (128–2048).
DATA_TYPE       [default: int]   Element type: "int" or "float".
HAMMING_DIST    [default: 1]     Distance metric: 0 = cosine similarity, 1 = Hamming (bipolar).
TRAIN_ITERATIONS                 Number of training epochs (configurable via config JSON).
RedPerfBase/Stride/Extent        Reduction perforation knobs for the Hamming distance intrinsic.
ALGChoice                        Algorithm selection knob (3 choices) for distance computation.

== Configuration Test Results (2026-02-15, ISOLET, CPU, 10 epochs) ==

  DATA_TYPE=int,   HAMMING_DIST=0 (cosine):  accuracy 66.77%,  time ~25s   [WORKS]
  DATA_TYPE=int,   HAMMING_DIST=1 (hamming): CRASHES during compilation/execution
  DATA_TYPE=float, HAMMING_DIST=0 (cosine):  accuracy 66.77%,  time ~67s   [WORKS]
  DATA_TYPE=float, HAMMING_DIST=1 (hamming): accuracy 71.17%,  time ~72s   [WORKS]

Best accuracy: float + Hamming (71.17%)
